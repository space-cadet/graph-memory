# T8: Background Processing Queue
*Created: 2026-06-19*
*Last Updated: 2026-07-08*

**Description**: Decouple graph extraction from heartbeat to prevent blocking. Heartbeat enqueues new sessions, background worker processes them asynchronously.

**Status**: ✅ **completed**
**Priority**: 🟡 medium
**Started**: 2026-06-19
**Completed**: 2026-06-25
**Last Active**: 2026-07-08T12:30:00Z
**Phase**: 3 of 6

## What Was Built

### `scripts/queue-worker.cjs`
- SQLite-backed job queue (`extraction_queue` table)
- Auto-enqueues new session JSONL files
- Processes batches of 5-10 sessions
- `--watch` mode for continuous background processing
- `--status` for queue health monitoring

### Current Operational Stats
- **Worker running since**: 2026-06-25 (PID 987943)
- **Sessions processed**: 9,543 completed, 74 failed
- **Queue status**: Caught up (0 pending)
- **Heartbeat integration**: Rotation 3rd heartbeat enqueues new sessions

### Architecture
```
Heartbeat (every 2nd)          Background Worker (always on)
    │                                    │
    ▼                                    ▼
┌──────────────┐                ┌──────────────────┐
│ Find new     │                │ Poll queue every │
│ .jsonl files │───────────────▶│ 30s for pending  │
└──────────────┘                │ jobs             │
                                └──────────────────┘
                                         │
                                         ▼
                                ┌──────────────────┐
                                │ Run session-     │
                                │ entity-extractor │
                                │ on each file     │
                                └──────────────────┘
```

## Why It Matters

Before T8: Heartbeat ran extraction synchronously → blocked for minutes.
After T8: Heartbeat enqueues in <100ms → worker processes independently.
