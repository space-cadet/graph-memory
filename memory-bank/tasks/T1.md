## Details

Integrate graph build into heartbeat rotation. Run every 2nd heartbeat alongside journal processing. Use `session-entity-extractor.cjs` for incremental updates.

### Current State (2026-08-30)
- **Worker:** `graph-memory-worker.service` (systemd user service)
- **Queue worker:** `scripts/queue-worker.cjs` — processes extraction queue every 30s
- **SQLite driver:** Triple fallback (`better-sqlite3` → `node:sqlite` → `sqlite3`)
- **Runtime:** Survives `node_modules` cleanup thanks to `node:sqlite` fallback
- **Native binary:** `native/better_sqlite3.node` extracted for persistence across cleanups

### Architecture
```
Heartbeat → enqueue new sessions → SQLite queue → queue-worker.cjs → entity extraction → graph.db
```

### Queue Statistics (as of 2026-08-30)
- 9,955+ session files processed
- Incremental watermark-based processing
- `.jsonl.gz` compressed session support added 2026-07-29
- Worker restartable without `better-sqlite3` (uses `node:sqlite` fallback)
